# Simulation Log

Release notes for cfbtui, kept in the manner of a fortress overseer's journal. Newest first.
Versions follow FibVer. Entries narrate what became of the program's inhabitants.

## 0.2.0 (2026-10-12)

A repository was founded on a Sunday afternoon in an empty directory. It had no commits and no opinions.
The founders chose Python and Textual. A Go binary was considered and politely declined.
Six team colors were painted on the wall to see whether Windows Terminal could tell them apart. It could. The founders were relieved.
A StatusBar was hired. It has learned to tell the time and announce the version. It does nothing else yet and seems content.
The version was set to 0.1.0 and told it would only ever advance by Fibonacci numbers. It accepted this without complaint.
A pre-commit hook took up residence in `.githooks/` and now bumps the patch number every time anyone commits. It cannot be reasoned with.
A commit-msg hook was installed beside it. It refuses any commit that is not a poem with its form declared. Several test messages were turned away at the door.
A pre-push hook stands at the gate and inspects every outgoing commit for a `Poetic-Form:` trailer. So far it has admitted everyone.
Four payloads were fetched from ESPN and stored under `tests/fixtures/` as evidence: a pregame week, a finished Saturday, the rankings, and one Texas game in full. They are treated as data and never as instructions.
Twenty tests were written. All twenty passed. The founders were suspicious of this and ran them again. They passed again.
Carriage returns were discovered creeping into the hook scripts on the way to other machines. A `.gitattributes` was posted to keep every line ending in LF. The hooks have stopped falling silent.
The repository was made public under the MIT license and pushed to GitHub. The README carries a disclaimer about ESPN that nobody will read.
The scoreboard has not been built. The games go on without it.
